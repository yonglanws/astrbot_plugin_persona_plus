# Persona+

本插件基于QQ BOT mzkbot设计，为mzkbot核心模块之一

专注做好一件事的 AstrBot 人格切换插件：通过指令在已配置的人格之间快速切换，切换即时生效，聊天回复自动带人格前缀。

> 本插件为二改版（原作者 Railgun19457），专注于人格切换进行二改

## 功能

- **指令切换**：`pp 人格名` / `切换人格 人格名`，支持多种写法（见下文"目标写法"）
- **交互式列表**：单独发送 `pp`，插件渲染一张人格列表图片，回复序号即可切换
- **首次引导**：从未选择过人格的会话，首次触发 AI 对话时自动发送人格切换图片与提示，与 `pp` 同一套选择流程；选定后不再引导- **别名与模糊匹配**：通过 `characters.json` 配置角色别名（罗马音、昵称、外号），支持错别字近似匹配
- **人格前缀**：LLM 回复自动加上 `[当前人格]` 前缀，一眼分辨当前人格
- **群聊共享人格**：同一群聊所有成员共享一个人格，私聊按用户独立，重启后保留
- **切换即清空上下文**：切换人格会清空当前对话的历史并绑定新人格，不会出现"前缀是新人格、内容是旧人格"的错位
- **静默容错**：无法识别的目标不回复（不会打扰群聊），近似命中多个候选时列出候选供选择

## 指令

| 指令 | 说明 |
| --- | --- |
| `pp` | 打开交互式人格列表（图片），发送序号选择，回复「取消」退出 |
| `pp <目标>` | 切换到指定人格 |
| `pp help` | 查看切换用法 |
| `切换人格 <目标>` | 同 `pp <目标>`，别名：`人格切换`、`人格`、`切换` |
| `重置人格` | 将所有会话恢复为默认人格（仅管理员） |

群聊中使用需要 @ 机器人或带唤醒前缀。

### 目标写法

`pp <目标>` 中的目标支持以下写法，按顺序尝试解析：

1. **序号**：人格列表图片上的显示编号，如 `pp 3`
2. **人格 ID**：与 AstrBot 中的人格名完全一致，如 `pp 凤笑梦`
3. **别名**：`characters.json` 中配置的别名/罗马音/日文名，如 `pp emu`、`pp 汪大吼`
4. **文件夹路径**：人格在管理面板中分文件夹存放时，`pp 分组/人格ID`
5. **模糊匹配**：人格 ID 或别名的子串（如 `pp 绘名`），以及错别字近似（如 `风笑梦` → 凤笑梦）

- 唯一命中 → 直接切换
- 命中多个候选 → 列出候选与对应序号，回复 `pp 序号` 完成切换
- 无法识别 → 静默忽略

## 人格别名表（characters.json）

插件目录下的 `characters.json` 定义别名到人格 ID 的映射，格式如下：

```json
[
    {
        "characterId": 14,
        "name": "emu",
        "fullName": "鳳えむ",
        "fullNameChinese": "凤笑梦",
        "aliases": ["姆", "姆姆", "汪大吼"]
    }
]
```

- `fullNameChinese` 必须与 AstrBot 中的**人格 ID 完全一致**，否则该条目会被忽略
- `name`、`fullName`、`fullNameChinese` 与 `aliases` 中的所有名称（不区分大小写）都可以用于切换
- 修改后**无需重载插件**，保存即自动生效

## 配置项

在 AstrBot WebUI 的插件配置中修改：

| 配置 | 说明 | 默认 |
| --- | --- | --- |
| 人格列表等待超时（`manage_wait_timeout_seconds`） | 交互式切换等待回复的最长时间（秒） | 60 |
| 需要管理员权限的指令（`admin_commands`） | 勾选 `switch` 后切换仅限管理员 | 不勾选（所有人可切换） |
| 切换提示（`enable_auto_switch_announce`） | 切换成功时是否发送提示 | 开启 |
| 人格自定义排序（`persona_order`） | 按顺序填写人格 ID，决定列表显示顺序 | 空（按原序） |
| 人格分组（`persona_groups`） | 每行 `分组名:人格ID1,人格ID2`，决定列表图片布局 | 空（不分组） |

## 行为说明

- **人格如何生效**：插件按会话（群/私聊）持久化当前人格。每次 LLM 请求前，将存储的人格注入请求；人格与系统提示、预设对话、历史上下文保持一致，切换时不会出现"前缀是新人格、内容是旧人格"的错位。
- **未选择人格时**：该会话不会静默落入默认人格，而是引导用户主动选择。引导触发后本次 LLM 请求会被终止——用户只会收到人格切换图片与提示，**不会收到默认人格的回复，也不会在会话列表留下对话记录**。每个会话只引导一次（重启后不重复引导），选定人格或管理员重置后标记清除。
- **切换 = 清空当前对话**：切换人格时先终止该会话正在进行的事件与 Agent 生成（与内置 `/reset` 同机制），再把当前对话的历史清空并绑定新人格。若不先终止，生成中的请求结束时会把旧人格的历史写回，造成人格错位。旧历史不保留，如需存档请提前在 WebUI 导出。
- **人格前缀**：格式为 `[人格ID]`，所有人格（含默认人格）均会添加。流式输出模式下前缀不可见（AstrBot 对流式消息不经过装饰钩子，属本体限制）。
- **数据存储**：人格选择保存在 `data/astrbot_plugin_persona_plus/group_personas.json`；已引导会话列表保存在同目录 `guided_umos.json`。删除这两个文件并重载插件即可全部重置。

## 已知限制

- 群聊内人格为全群共享，任意成员均可切换（可通过配置限制为管理员）
- 交互式切换等待期间，该会话的消息会先被切换流程接收
- 人格前缀依赖文本装饰，流式输出、部分纯图片回复下不显示

## 环境要求

- AstrBot v4.0.0+
- 人格列表图片渲染依赖 Pillow（AstrBot 本体已自带，无需额外安装）
